## 01 / Thesis

I'm **Soheil Salmani**, a DevOps Engineer and Mathematics and Applications undergraduate at **Kharazmi University**, with a secondary focus on Computer Science.

I like problems that have both a formal side and an operational side: where **state, assumptions, error, constraints, and failure** can be made explicit.

> **I care about systems that can be reasoned about before they fail, observed while they run, and recovered when they do.**

My path into DevOps came through Python/backend work, technical leadership, data engineering, and analytics. That history still shapes how I work: infrastructure is part of the software system, not something that begins after the application is written.

## 05 / Principles

**Reproducible over clever.** If someone else cannot obtain the result, it is difficult to trust.

**Observable over mysterious.** Important state should be visible.

**Recoverable over fragile.** Failure belongs in the model.
